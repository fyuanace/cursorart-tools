# cursor极简工具

[cursor极简](https://github.com/fyuanace/cursorart) 主题的配套插件。

思源集市新上架主题不再允许携带 `theme.js`，因此主题的交互能力改由本插件提供：

- 左右侧栏顶部 dock、顶栏显隐按钮
- 主题设置（插件菜单 → **cursor极简 设置**）
- 路径面包屑、大纲跟随、文档引用图标
- 文件树收藏与最近打开
- 顶栏前进旁的喜欢 / 支持爱心

## 安装

1. 安装并启用主题 **cursor极简**（`cursorart`）
2. 安装并启用本插件
3. 若侧栏未挂载，重启一次思源

## 说明

配置仍写在 `/data/storage/theme/cursorart/config.json`，与原先主题 JS 兼容，旧设置会保留。
