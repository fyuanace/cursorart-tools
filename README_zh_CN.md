# cursor极简工具

[cursor极简](https://github.com/fyuanace/cursorart) 主题的配套插件。

思源集市新上架主题不再允许携带 `theme.js`，因此主题的交互能力改由本插件提供。

## 主题门禁

**侧栏顶部工具条**与**标题栏高度**仅在当前亮色/暗色主题为 `cursorart`（cursor极简）时生效；换用其他主题会自动还原。其它能力（设置、收藏、最近打开、喜欢按钮等）仍可用。

集市**不会**在安装主题时自动装插件，也不会在安装插件时自动装主题，需两边都装。若当前不是 cursor极简，插件会提示一次。

## 安装

1. 安装并启用主题 **cursor极简**（亮色与暗色都选它）
2. 安装并启用本插件
3. 若侧栏未挂载，重启一次思源

## 说明

配置仍写在 `/data/storage/theme/cursorart/config.json`，与原先主题 JS 兼容。
