# cursor极简工具

[cursor极简](https://github.com/fyuanace/cursorart) 主题的配套插件。原 **fhelper** 能力已并入本插件，请禁用 fhelper，以免子文档导航重复植入。

思源集市新上架主题不再允许携带 `theme.js`，因此主题的交互能力改由本插件提供。

## 设置

顶栏插件菜单 → **cursor极简工具**（或集市卡片齿轮）。无保存按钮，每项立刻生效并写入。

| 页签 | 何时可用 |
|------|----------|
| 侧栏 | 仅当前主题为 cursor极简 |
| 样式 / 编辑 / 斜杠菜单 / 配置同步 / 关于 | 任意主题 |

配置文件：`/data/storage/theme/cursorart/config.json`（首次会从 fhelper 的 petal 配置迁入编辑类字段）。

## 安装

1. 安装并启用主题 **cursor极简**（亮色与暗色都选它）
2. 安装并启用本插件
3. **禁用 fhelper**
4. 若侧栏未挂载，重启一次思源
