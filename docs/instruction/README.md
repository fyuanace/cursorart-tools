# cursor极简

当前匹配版本：主题 **v2.0.10**，插件 **v1.2.8**。

**参考 Cursor 和 Notion 优化布局和交互，主打简洁、现代化，提供中英文空格间隔、图片优化、收藏等呼声较高的功能。请务必插件和主题一起使用。**

只装主题，没有收藏、子文档索引、配置同步等交互。

只装插件，侧栏布局和外观优化也对不齐。

亮色 / 暗色请都选 **cursor极简**。设置入口：顶栏插件菜单 → **cursor极简工具**。

## 特色功能

### 1. 主题显示优化

- 界面简化美观，侧栏收干净，编辑区更大。
- 文档树带收藏和最近打开，样式参考 Notion。
- 大纲去掉 H1–H6 标记，一级标题加粗，层级一眼能看清。

### 2. 文档相关控制

- 面包屑显示当前文档路径，可点上级。
- 面包屑一键收藏，不用钻进原生很深的入口。
- 文件树顶部列出最近打开。
- 自动在正文植入子文档索引块，也能按索引删掉对应子文档。

### 3. 菜单按钮隐藏

- 可隐藏侧边工具栏按钮，少占空间。
- 可隐藏斜杠菜单里用不到的命令。

### 4. 编辑相关

- 中文和英文之间自动插空格，Markdown 更好读。
- 图片按 DPI 缩放，不会贴进来特别大，并自动居中。
- 文档引用可带图标显示。
- 块行间距可调。

### 5. 软件设置同步

- 多台电脑配置不同步很烦，可一键同步软件配置和主题安装内容。

## 主题显示优化

官方界面分区碎、装饰多，写久了容易累。

本主题叠在 daylight / midnight 上，只改布局，配色仍走官方。

侧栏工具收到内容区顶部横条，中间留给正文。

文件树顶部的收藏、最近打开做成 Notion 那种简洁列表，点哪条只高亮哪条。

大纲不再显示文档名和 Hx 标记，一级标题加粗，滚动正文时大纲跟着走。

<img src="../../image/display.png" alt="主题显示优化：收藏、最近打开、侧栏与大纲" width="720">

## 文档不好找、子文档难管

官方面包屑跟的是块标题，不是文档树路径。

这里改成「笔记本 / 文件夹 / 当前文档」，空间不够时中间变成 `...`，悬停能看到到这一级的完整路径。

原生收藏入口深，面包屑左侧一颗星就能收藏当前文档。

最近打开钉在文件树顶部，不用在树里翻。

子文档默认不像 Notion 那样在正文里有一层索引。

打开文档时会自动植入当前层子文档块；也能按这些索引删除对应子文档。

<img src="../../image/docs-path.png" alt="文档路径面包屑与文档引用样式" width="720">

<img src="../../image/docs-child.png" alt="子文档索引：正文植入并出现在大纲" width="720">

## 菜单按钮太多

左侧竖条 dock 图标常年占位。

设置里可按需隐藏；侧栏布局开关只在 cursor极简下生效。

斜杠菜单太长，常用项被淹没。

可在设置里关掉用不到的斜杠命令，输入 `/` 更干净。

## 编辑体验

中英文挨在一起难读。

输入和粘贴时自动在中文与英文之间插空格。

高 DPI 下图片经常撑满整栏。

粘贴后按系统 DPI 缩放宽度，并让图片段落居中。

文档引用和普通文字不好区分。

默认开启链接样式，给文档引用加上图标。

段落有时过密或过疏。

样式里可调块行间距。

<img src="../../image/editing.png" alt="编辑体验：高 DPI 图片缩放与中英文空格" width="720">

## 多台电脑配置不同步

思源不同步 `/conf` 里的软件设置和自定义主题。

配置同步把设置和主题拷进工作区 data，再走官方同步。

一台点「覆盖云端配置」，另一台点「下载云端配置」后重启即可。

须先启用思源官方同步或 S3。

<img src="../../image/config-sync.png" alt="配置同步：覆盖与下载云端配置" width="720">

## 安装

1. 安装主题 **cursor极简**，亮色和暗色都选它。
2. 安装并启用插件 **cursor极简工具**。
3. 若仍装着 **fhelper**，请禁用，避免子文档索引重复植入。
4. 侧栏没挂上时，重启一次思源。

主题：[cursorart](https://github.com/fyuanace/cursorart)　插件：[cursorart-tools](https://github.com/fyuanace/cursorart-tools)
